# java-calculator-precourse
## 기능 요구 사항

- 기본 구조 및 빈 문자열을 처리
  - 입력 문자열이 `빈 문자열`인 경우 `0`을 반환한다.
- 문자열이 단일 숫자로만 이루어진 경우 처리
  - 구분자 없이 숫자 하나만 포함된 문자열을 처리한다.
- 기본 구분자 처리
  - `쉼표`로만 이루어진 문자열을 처리한다. 
  - `콜론`으로만 이루어진 문자열을 처리한다.
  - `쉼표`와 `콜론`으로 이루어진 문자열을 처리한다.
- 커스텀 구분자 처리
  - `//`와 `\n` 사이의 문자를 커스텀 구분자로 지정하여 처리한다.
- 예외 처리: 숫자가 아닌 값 포함
- 예외 처리: 음수 값 포함
- 사용자 입출력 인터페이스 구현
